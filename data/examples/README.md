# Workshop examples

This directory intentionally contains no private images in source control.

Add only image pairs that are licensed and approved for public sharing. Use this naming convention so the UI discovers pairs automatically:

```text
<pair>_A_reference_ok.png
<pair>_B_test_error.png
```

For local development, mount a complete organized data tree with `VISUAL_INSPECTION_DATA_DIR`. Put approved examples under `derived/workshop-pairs`.
